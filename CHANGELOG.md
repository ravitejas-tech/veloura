# Changelog

## 1.0.0 (2026-09-26)

Initial release.

- Next.js 16 (App Router), React 19 and TypeScript, exported as a static site.
- Sections: Hero, marquee ribbons, Occasions panels, The Lavender Edit (bento product grid), Build a Box, Our Studio sticky story, lavender-field quote, Love Notes, #Moments gallery, newsletter envelope, footer.
- All copy, products, prices, images and links in `src/content/`.
- SEO: metadata, canonical URL, Open Graph and Twitter cards, JSON-LD (OnlineStore, WebSite, Products), sitemap.xml, robots.txt, web manifest, favicon.
- Self-hosted Google Fonts via `next/font`.
- Accessible, responsive (1080 / 860 / 600px breakpoints) and reduced-motion aware.
